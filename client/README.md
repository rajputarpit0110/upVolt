# ⚡ upVolt - Client (Frontend)

The frontend for **upVolt** built with React 19, Vite, and modern Vanilla CSS styling.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Development Server
```bash
npm run dev
```
Runs the Vite development server on `http://localhost:5173`.  
Any `/api` requests will be proxied to `http://localhost:5001`.

### 3. Build for Production
```bash
npm run build
```
Generates production-ready static assets in the `dist/` folder.

### 4. Linting
```bash
npm run lint
```
Runs `oxlint` for fast code linting.
